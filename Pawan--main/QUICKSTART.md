# 🚀 Quick Start Guide - Backend Setup

## ✅ Your Backend is Ready!

### What was added:
- **server.js** - Express backend server
- **admin.html** - Order management dashboard
- **Checkout Form** - Customer order submission
- **SQLite Database** - Automatic order storage

---

## 🎯 3-Step Setup

### 1️⃣ Install Dependencies
```bash
npm install
```

### 2️⃣ Start the Server
```bash
npm start
```

### 3️⃣ Open Admin Panel
Go to: `http://localhost:3000/admin.html`

**That's it!** Your backend is running! 🎉

---

## 📱 Customer Journey

1. Customer adds items to cart
2. Clicks "Place Order" button
3. Fills in name, phone, address
4. Order saved to database
5. You see it in admin panel

---

## 💡 Two Checkout Options

Customers can choose:
- **Place Order** (saves to your database)
- **Checkout via WhatsApp** (sends to +918349206021)

---

## 📊 Admin Dashboard Features

✅ View all orders  
✅ See order details  
✅ Mark orders as completed  
✅ Track statistics (revenue, pending, etc.)  
✅ Auto-refresh every 30 seconds

## ⚠️ Keep Server Running

The terminal with `npm start` must stay open while you're using the website!
